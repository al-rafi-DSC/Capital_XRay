# A2B_Games

Hackathon project. Working directory: `Data_Analysis/A2B_Games`.

## Goal

Build something **interactive** with **AI implemented** in it, and make it interesting
enough to stand out in a hackathon judging context.

## Status

Scaffolding stage. No application code written yet — the concept is still open.

## Shared memory

This repo is registered with the `codebase-memory` MCP server as project **`a2b-games`**.
Both Claude Code and ChatGPT connect to the same server, so architecture decisions and
the code graph stay in sync across tools. See the ADR (`manage_adr`) for running context.
